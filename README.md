## 📝 Descripción del caso

Veterinaria San Marcos es una clínica veterinaria ubicada en Rancagua que atiende un promedio de 25 pacientes al día (perros, gatos, conejos y aves), pero gestiona sus citas y fichas clínicas de forma manual, en papel. Esto genera pérdida de fichas, duplicidad de horarios y un 20% de inasistencia por falta de recordatorios. La aplicación digitaliza el agendamiento de citas, las fichas clínicas y el historial de vacunación, permitiendo a los dueños de mascotas solicitar horas en línea y a la clínica operar de forma más eficiente y ordenada.

## 🗂️ Estructura del proyecto

El proyecto sigue la metodología **Atomic Design** para la organización de componentes dentro de `src`:

```
src/
├── components/
│   ├── atoms/
│   ├── molecules/
│   ├── organisms/
│   ├── templates/
├── pages/
├── App.css
├── App.jsx
├── Index.csss
└── main.jsx
```

## ▶️ Cómo ejecutar el proyecto

1. Clonar el repositorio:
   ```bash
   git clone [URL_DEL_REPOSITORIO]
   ```
2. Ingresar a la carpeta del proyecto:
   ```bash
   cd veterinaria-san-marcos
   ```
3. Instalar las dependencias:
   ```bash
   npm install
   ```
4. Ejecutar el proyecto en modo desarrollo:
   ```bash
   npm run dev
   ```
5. Abrir en el navegador la URL que indica la consola (por defecto `http://localhost:5173`).
